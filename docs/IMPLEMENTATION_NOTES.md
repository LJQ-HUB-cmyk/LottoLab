## 2026-09-12：首版实现与范围取舍

- 原生默认改为 SQLite，以交付无需 Docker 即可使用的工作台；保留同一 SQLAlchemy 模型、Alembic 迁移和 Compose PostgreSQL 路径。现有 PostgreSQL 配置私有备份，官方响应快照恢复到 SQLite，旧 PostgreSQL 实验未迁移。
- Docker Desktop 的两个旧通信文件在恢复环境中无法正常访问。第一处临时目录备份成功，第二处清理被自动审批阻断；没有通过切换删除工具或更改保护设置继续该操作。本地请求禁用系统代理继承，系统代理配置未修改。
- 前端采用 React + Vite，构建静态文件由 FastAPI 提供；无需长期运行额外 Node 服务。Compose 为 db/API/worker 三个服务。
- 统计用 NumPy/SciPy，模型用 scikit-learn；没有引入未使用的 pandas、分布式计算、独立消息队列或模型服务。数据库使用五张实际业务表，结果和冻结数据采用 JSON。
- 模型使用固定超参数，管道在训练侧拟合；不引入自动搜索或独立校准器。基数投影说明其边际语义。所有任务记录执行版本，模型种子不依赖其他模型的选择顺序。
- 覆盖算法先实现贪心、条件精确枚举与完整主区空间估计；局部搜索等方法作为后续研究。禁止把候选池内覆盖率称为无条件中奖保证。
- DLT 已扩展到号码、数据、统计和四模型回放，但历史奖金版本未完整建模，禁用 ROI。SSQ 按实际历史每注奖金税前结算；缺失则不输出完整收益。
- 末段回放窗口与主要指标按本次运行固定，允许之后更新训练数据；没有声称具备预登记、不可重复访问的确认性检验区或全历史参数搜索校正。
- 修订审计保存最终入库值，含从旧记录保留的奖金字段；开奖及冻结数据包含来源导入 ID。相关回归通过。
- Windows 启动器管理整个服务进程树，实际验证启动、重复启动、停止、重启和数据保留。备份脚本生成一致性 SQLite 副本及原始快照清单。
