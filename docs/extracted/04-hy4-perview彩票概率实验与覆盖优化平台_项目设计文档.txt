# 彩票数据分析与概率实验平台 — 项目设计文档

> v1.0 ｜ 角色：高级数据工程师 / 机器学习工程师
> 核心立场：彩票开奖是独立随机过程，**不存在可稳定超越均匀基线的预测信号**。本项目的科学价值不在"提高中奖率"，而在于——①用工业级管线 + 严格回测**可复现地证伪**各类预测神话；②在确认不可预测的前提下做真正有数学价值的事：**组合覆盖优化**；③建**概率素养教育**工具。所有"预测"输出 = 概率分布 + 强制免责 + 负 EV 提示，**不构成购彩建议**。

---

## 1. 项目背景

- **需求侧**：民间"彩票预测"内容泛滥（冷热号、走势图、AI 预测），全部缺乏对照实验、无统计检验、无 EV 披露，本质是幸存者偏差与事后叙事。
- **供给侧缺口**：缺少一个**方法论正确**的开源参照实现——把金融级回测严谨性（前视偏差防护、多重检验校正、Walk-Forward）迁移到彩票场景。
- **工程价值**：完整闭环（爬取→清洗→特征→建模→回测→API→前端），是一套标准的概率建模工程样板，可复用于任何"低频离散事件"场景。
- **标的**：双色球（SSQ：红 33 选 6 + 蓝 16 选 1）、大乐透（DLT：前区 35 选 5 + 后区 12 选 2）。总组合数 `C(33,6)×16 = 17,721,088`；`C(35,5)×C(12,2) = 21,425,712`。

---

## 2. 项目真实目标

| 目标层级 | 内容 | 可证伪产出 |
|---|---|---|
| 主目标 | 证伪"可预测性"：任一模型须 beat 均匀基线 log-loss，否则判定无效 | 统计检验报告（含 p 值、置信区间、多重检验校正） |
| 副目标 | 组合覆盖优化：给定注数 N，最大化 k-覆盖度 / 最小化合买内部重复 | 覆盖设计算法 + 实测覆盖率 |
| 副目标 | 概率教育：EV、破产概率、大数定律可视化 | 交互实验页（蒙特卡洛） |
| 工程目标 | 可复现管线 + 服务化（API + 前端） | Docker Compose 一键起、CI 通过 |
| **非目标** | 不荐号、不售号、不承诺中奖、不提供"必中方案" | —— |

**关键量化锚点（双色球，单注 2 元）**：返奖率约 50%，即 **EV ≈ -1.0 元/注**；单注中一等奖概率 `1/17,721,088 ≈ 5.64e-8`；整体中奖率约 6.7%。**任何策略的数学期望恒为负，与选号方式无关**——这是全项目的第一性原理。

## 3. 彩票预测是否可行：统计学解释

**结论：不可行（对"提高中奖率/正 EV"而言）。**

### 3.1 数据生成过程假设
每期开奖是从离散均匀分布上的**独立抽样**：红球 `~ Uniform(C(33,6))`，蓝球 `~ Uniform(16)`。核心性质：

- **独立性**：`P(X_t | X_{t-1}, ..., X_1) = P(X_t)`。历史不包含关于未来的信息。
- **无记忆性**：遗漏值再大，下一期出现概率恒为 `6/33`（红球单号边际）。"冷号回补"是赌徒谬误。
- **可交换性**：序列顺序对联合分布无任何信息量 → 任何时序模型（LSTM/Transformer）在总体层面无信号可学。

### 3.2 为什么"看起来有规律"
- **模式幻觉**：人类视觉在随机点阵中必然发现"簇/空缺/对角线"（聚类错觉）。
- **多重比较**：33 个号码 × 数十种指标 × 数千期 = 必然产生 p<0.05 的"显著异常"，纯属多重检验假阳性。
- **幸存者偏差**：只传播"中了的预测"，沉默的失败预测基数不可见。

### 3.3 信息论下界（硬基线，模型必须 beat）
单注（6 红 + 1 蓝）在均匀分布下的期望 log-loss：

```
Baseline(SSQ) = ln(C(33,6)) + ln(16) = 13.918 + 2.773 = 16.691 nats/注
Baseline(DLT) = ln(C(35,5)) + ln(C(12,2)) = 15.061 + 4.190 = 19.251 nats/注
```

逐号边际：`ln(33)=3.497`（红球单号），`ln(16)=2.773`（蓝球）。**均匀基线就是理论最优**——任何偏离均匀的模型，在真实 i.i.d. 数据上的期望 log-loss 必然 **≥** 基线，差的幅度 = 它与均匀分布的 KL 散度（恒 ≥0）。

### 3.4 那模型还能做什么？
- 只能在**非平稳**成分上可能有微弱信号：规则变更、销量对奖池的影响（影响的是**奖金**而非**号码**）、以及浮点伪随机偏差（摇奖机物理微偏——若有，量级约 1e-4 且远小于套利成本）。
- **真正可优化的：注集层面的覆盖结构**（见 §8.9）。给定买 N 注，可优化"至少中 6 红的最小 N"、"合买去重"等——这是**组合设计问题，不是预测问题**，有确定性的数学收益。

## 4. 可落地项目定位

**产品名**：`LottoLab — 彩票概率实验与覆盖优化平台`
**定位**：开源、可复现的**概率科学实验平台 + 覆盖优化工具 + 风险教育站**（非荐号工具）。

**三条能力线**

1. **数据中枢**：官方开奖数据自动同步、清洗、版本化管理、数据质量 SLA。
2. **实验台（核心）**：基线 vs 候选模型，在 Walk-Forward + 蒙特卡洛合成数据双轨下做统计检验，输出"是否可预测"的公开结论。
3. **覆盖优化器（唯一真实业务价值）**：给定预算 N 注 + 目标（如"保证中 5 红"或"最大化 6 红覆盖"），用贪心/ILP/覆盖设计生成**结构最优**注集；对合买场景做去重与多样性控制。

**明确不做**：付费荐号、代购、投注接口、"中奖概率提升"话术。

## 5. 数据来源与字段设计

### 5.1 数据源
- 主源：中国福彩 / 体彩官网开奖公告页（双色球、大乐透），HTML/JSON 抓取。
- 备源：官方微信/授权数据接口的公告镜像，用于交叉校验（一致性 < 100% 则告警）。
- 同步频率：开奖日 21:30 后触发，指数退避重试 5 次；T+1 全量对账。
- 合规：仅采集已公开开奖结果，控制速率（≤1 req/3s），遵守 robots，注明来源，不做商业转售。

### 5.2 表设计（PostgreSQL + TimescaleDB）

**`dim_lottery`（彩票维表）**

| price_cny | NUMERIC(4,2) | 2.00 |
| rules_json | JSONB | 各奖级中奖条件与分配规则（版本化） |

## 6. 数据清洗规则（Data Quality 层）

### 6.1 硬校验（失败即拒绝入库 + 告警）
1. **完整性**：`red_balls` 长度 == red_pick，`blue_balls` 长度 == blue_pick。
2. **值域**：`1 ≤ ball ≤ red_max`（蓝球同理）。
3. **无重复**：单注内号码 `len(set) == len(list)`（彩票为无放回抽样）。
4. **期号唯一**：`issue_no` 主键冲突 → upsert 并记录 `data_revision`。
5. **期号连续**：`issue_no` 与上一期差值应为 1（年切例外），断裂 → 标记 `gap_flag=true` 并触发补抓。
6. **类型安全**：销量/奖池为非负 BIGINT，单位统一为元（原始"万元"需 ×1e4）。

### 6.2 软处理
- **归一化**：号码升序排序；日期统一 `Asia/Shanghai`；全角/空格 trim。
- **幂等**：`src_hash = sha256(lottery+issue+red+blue)`，重复抓取只更新时间戳。
- **不可变历史**：历史开奖为既成事实，`fact_draw` 只允许 INSERT；更正走 `fact_draw_amend` 审计表 + `is_superseded` 标记，**禁止原地 UPDATE 中奖号码**（防 retroactive 污染回测）。
- **规则版本切分**：新增 `rule_version` 字段；历史规则变更点（如奖级/球数调整）前后数据**不可混用于同一模型训练**，用 `effective_from` 切分。
- **交叉校验**：主源 vs 备源不一致 → 状态置 `pending_review`，不进入训练集。
- **质量门禁（CI）**：每日跑 `great_expectations` 断言（非空、唯一、值域、连续性、无未来期号），失败阻断下游 pipeline。

## 7. 特征工程清单

> **重要声明**：以下特征在 i.i.d. 假设下**理论上均无预测力**。构建它们的目的，是给候选模型"最大公平机会"去尝试 beat 基线 —— 若在此特征集上仍无法 beat，则结论（不可预测）才是稳健的。这是**证伪实验的设计要求**，不是相信它们有用。

### A. 频率/遗漏类（每号每期）
- `freq_{N}`：近 N 期出现次数（N ∈ {10, 30, 100, 500, all}）
- `omission`：当前遗漏期数（距上次出现）
- `omission_max_hist` / `omission_mean_hist`：历史最大/平均间隔
- `omission_ratio = omission / omission_mean_hist`（"过热/过冷"指标）
- `hot_z`：`(freq_N - N*p) / sqrt(N*p*(1-p))`，`p=6/33`，标准正态 z 分数

### B. 组合结构类（每期标量）
- 和值 `sum`、跨度 `span`、AC 值、连号组数、最大连号长度
- 奇偶比、大小比、质合比、012 路（mod 3）分布
- 三区（1-11/12-22/23-33）计数、区间熵
- 与上期的**重合号数** `overlap_prev`、`overlap_{k}`（k=2..5 期）
- 和值的滚动 z-score（窗 100 期）

### C. 时序/自相关类
- lag 1~20 期的一号 one-hot（33 维 × lag）→ 展平
- 滚动均值 / EWMA（α=0.05/0.2）
- 和值序列的 ACF/PACF（lag 1~20）、Ljung-Box 统计量
- 游程检验（Wald–Wolfowitz）z 值、方差比（Variance Ratio）

### D. 分布拟合类
- 每号出现次数对**二项分布** `B(N, 6/33)` 的偏差、卡方统计量、KS 统计量
- 和值分布对理论组合分布（卷积精确解）的 KL 散度
- 整体号码频次对**多项均匀分布**的 G-test

### E. 共现/关联类
- 33×33 号码共现矩阵（滚动 200 期），PMI / lift / Jaccard
- 关联规则（Apriori，min_support=0.02）的置信度与提升度
- 红球-蓝球互信息 MI
- 图特征：共现图（节点=号码）的度中心性、PageRank、社区标签

### F. 外部/元信息类
- 销量、奖池、`p1_cnt`、单注奖金、是否节日、是否加奖活动期
- 期号奇偶、年内第几期、距上次规则变更期数

### G. 目标与泄露防护
- **目标** `y`：下一期 `red_balls` 的 33 维 multi-hot + `blue` 的 16 维 multi-hot（多标签分类）；或整注组合的 softmax（不可行，17M 类 → 改为逐号边际建模）
- **泄露红线**：所有 rolling 特征必须 `shift(1)`；`scaler/encoder` 在**仅训练集**上 fit，写入 artifact；`feat_version` 随特征变更递增，保证结果可复现。

## 8. 模型方案对比

统一设定：输出 = 下一期每个号码的**边际概率向量**（红 33 维、蓝 16 维），整注概率按独立乘积近似（或 copula 修正）。

### 8.1 Baseline-Uniform（理论最优）
`p_i = 6/33`。log-loss = 3.497/号。**判定标准：所有模型必须显著 beat 它，否则 FAIL。**

### 8.2 经验频率 / 多项式 MLE
`p_i = count_i / total`。等价于在训练集上最小化 log-loss 的解析解。样本内必然优于均匀（过拟合），**样本外必然劣于或等**——这是最好的教学对照。

### 8.3 贝叶斯平滑（Dirichlet-Multinomial）
`p_i = (count_i + α) / (N + 33α)`，α 由验证集调（预期最优 α → ∞，即**收敛回均匀分布**）。**α 的最优取值本身就是"是否存在信号"的证据**：α→∞ 说明无信号。

### 8.4 马尔可夫链（一阶/二阶转移）
33×33 转移矩阵（或状态=和值区间）。输入 `X_{t-1}` → `X_t`。检验：转移矩阵各行与边际分布的卡方同质性检验，预期不显著。

### 8.5 时序模型 ARIMA / GARCH
仅用于和值、销量等标量序列。Ljung-Box 预期不显著 → 无自相关可建模。

### 8.6 GBDT（XGBoost/LightGBM/CatBoost）
输入 §7 全特征，33 个二分类（每号一个）或 One-vs-Rest。优势：处理非线性/交互；风险：在纯噪声上必然过拟合，须靠 Walk-Forward + 早停验证。

### 8.7 深度学习 LSTM / Transformer（TFT）/ Neural ODE
输入近 100 期序列。参数量大、极易记忆噪声。**重点观察其样本外 log-loss 是否劣于 GBDT（预期：是）**——这是"复杂模型在噪声上更糟"的实证。

### 8.8 生成式（VAE/GAN/Diffusion）
不用于预测，用于**注集多样性生成**与"看起来像真实彩票"的合成数据（辅助蒙特卡洛）。

### 8.9 组合覆盖优化（唯一真实价值模块）
- **覆盖设计（Covering Design）**：求最小注集 S，使任意 6 子集命中至少 t 个（`(n,k,t)`-covering）。
- **贪心 / 模拟退火 / ILP（OR-Tools CP-SAT）**：目标 `max |∪ Covered(t-subsets)| s.t. |S| ≤ N`。
- **合买去重**：MinHash + LSH 检测近重复注；最大最小距离（max-min diversity）采样保证注集分散。
- **输出**：给定预算 N 注，给出"保证中 k 红的最小 N"（双色球保证中 6 红需 1,107,568 注 ≈ 221 万元 —— **这个数字本身就是最好的风险教育**）。

### 8.10 模型选型判定流程
```
候选模型 → Walk-Forward 样本外 log-loss
        → 与 Baseline 做 Diebold-Mariano 检验
        → 多模型多重检验校正（White's Reality Check / DSR）
        → 蒙特卡洛合成数据复测
        → 结论：PASS / FAIL
```
**预期结论：全部 FAIL（除 §8.9 覆盖优化，其价值不依赖预测）。**

## 9. 回测框架

### 9.1 核心原则
彩票回测最大的坑是"看起来赢了"。用金融级严谨性封堵。

### 9.2 Walk-Forward（Expand / Roll）
```
min_train = 500 期
step      = 1 期（逐期滚动）
scheme    = expanding（默认）+ rolling(1000) 交叉验证
embargo   = 0（无重叠天然满足，但特征含 lag 时 purge = max_lag 期）
shuffle   = 禁止（时序不可打乱）
```
每期：用截至 `t-1` 的数据 fit（含 scaler/超参），预测 `t`，记录预测分布与真实结果。

### 9.3 前视偏差（Look-ahead）检查清单
- 所有 rolling 统计 `shift(1)` ✔
- scaler/encoder/特征选择 **只在 train fold 内 fit** ✔
- 超参搜索在 train 内再做 inner-Walk-Forward（嵌套 CV）✔
- 历史数据修正走 amend 表，**不用修正后的历史"重训过去"** ✔
- 单元测试：`test_no_future_leakage`（人为打乱特征顺序，loss 必须变差）

### 9.4 双轨验证：真实数据 + 蒙特卡洛合成数据（黄金标准）
生成 `M=200` 条长度 2000 期的**合成序列**（严格按均匀分布 i.i.d. 抽样）。

- **用途 1**：验证回测框架本身无 bug —— 若某模型在合成数据上"显著 beat 基线"，说明回测/检验流程有假阳性漏洞（框架失效，必须先修框架）。
- **用途 2**：给出检验统计量的**零分布**，用于精确 p 值（而非依赖渐近分布）。

### 9.5 多重检验校正（防 p-hacking）
测试 `K` 个模型/策略时，单一 p 值无意义。采用：

- **White's Reality Check / Hansen's SPA**：对"最佳策略是否真优于基线"做自助法检验。
- **Deflated Sharpe Ratio（类比迁移）**：根据尝试次数 K、策略收益分布的偏度/峰度，折算"最大 Sharpe 的期望"后再判定。
- **Bonferroni / Benjamini-Hochberg**：作为下限兜底。

### 9.6 下注模拟（EV 回测）
每期按策略生成 K 注（K ∈ {1, 10, 100}），按真实奖金规则（含奖池浮动、奖级截断）结算：

- 记录：每期成本、每期返奖、累计 ROI、资金曲线、最大回撤、**破产概率（ruin probability）**。
- 对照：`随机选号` 与 `机选` 两条基线，**预期三线收敛到 -50% ROI**。

### 9.7 产出物
`backtest_run` 记录：`model_id`, `scheme`, `date_range`, `n_folds`, `logloss_mean±se`, `dm_stat/p_value`, `spa_p_value`, `roi`, `max_drawdown`, `ruin_prob`, `verdict(PASS/FAIL)`, `git_sha`, `data_snapshot_hash`, `seed`。

## 10. 评估指标

### 10.1 概率质量（主指标，全部为"越小越好"）

| 指标 | 定义 | 硬基线（SSQ 单号/整注） |
|---|---|---|
| Log-Loss（红球单号） | `-Σ y log p`，33 维 multi-hot 平均 | **3.497** |
| Log-Loss（蓝球） | 16 维 | **2.773** |
| Log-Loss（整注） | 6 红 + 1 蓝独立乘积近似 | **16.691** |
| Brier Score | `mean((p - y)^2)` | `2*p*(1-p)` ≈ 0.302（红单号） |
| ECE（校准误差） | 分 10 桶，预测概率 vs 实际频率差 | 0（完美校准即均匀） |

**判定**：候选模型样本外 log-loss 的 **95% CI 上界 < 基线** 且 **DM 检验 p<0.05（经多重校正后）** → PASS。

### 10.2 统计检验（证伪工具）
- **卡方拟合优度**：号码频次 vs 均匀，`p` 应 > 0.05（无法拒绝均匀）。
- **KS 检验**：遗漏间隔 vs 几何分布。
- **Ljung-Box（lag 20）**：和值/号码序列无自相关。
- **Wald–Wolfowitz 游程检验**：序列 randomness。
- **Diebold-Mariano**：两模型 loss 序列差异的显著性。

### 10.3 命中/覆盖（面向 §8.9）
- 命中率 vs 理论（6.7%），`z = (obs - Np)/sqrt(Np(1-p))`。
- **Coverage@k**：注集 S 覆盖的 t-子集数 / 全部 `C(33,6)`。
- **多样性**：注集两两平均最小距离（Hamming），越高越好。
- **去重率**：合买场景重复注占比。

### 10.4 经济指标（风险教育核心）
- `EV = Σ p_i · prize_i - cost`（恒定 ≈ **-1.0 元/注**）
- `ROI`、`Sharpe-like = mean/std of per-period return`、最大回撤、**破产概率**（给定初始资金与每期投入，Kelly/Gambler's Ruin 数值解）。

### 10.5 特征有效性
- 特征重要性（SHUffle importance / gain）应与**置换噪声特征**的重要性分布无法区分 → 报告 `signal_to_noise_ratio ≈ 1.0`。

### 12.2 关键约定
- **强制免责**：`predict` / `combo/optimize` 响应体**服务端硬编码** `disclaimer` 与 `ev_per_note: -1.0` 字段，前端不可覆盖。
- 统一响应信封：`{code, message, data, trace_id, disclaimer?}`；错误码 4xxxx/5xxxx 语义化。
- 幂等：`Idempotency-Key` 头 for POST（训练/回测）。
- 限流：Redis 令牌桶，匿名 60/min、登录 300/min；抓取任务全局串行。
- 缓存：开奖数据 `Cache-Control: max-age=3600` + ETag；分析结果 Redis TTL 10min。
- 认证：JWT（管理端写操作）；只读端点匿名开放（利于开源透明）。
- 可观测：structlog JSON 日志 → Loki；Prometheus + Grafana（抓取延迟、数据质量、回测耗时）；Sentry 异常。
- 定时任务（Celery beat）：开奖日 21:35 抓取 → 21:40 数据质量检查 → 21:45 增量特征 → 21:50 基线预测落库；每周日 03:00 全量重训 + 回测。

## 16. 项目亮点总结

1. **方法论正确且诚实**：不回避"不可预测"的结论，把项目目标从"预测中奖"（不可能）重构为"证伪 + 覆盖优化 + 概率教育"（可行且有真实价值）——这是区分科学与玄学的关键。
2. **硬基线先行**：给出 `ln(C(33,6))+ln(16)=16.691` 的信息论下界，让"预测能力"变成**可量化、可证伪**的数字，而非话术。
3. **蒙特卡洛双轨验证（黄金标准）**：用已知随机的合成数据检验回测框架本身，杜绝 p-hacking 与框架假阳性 —— 这是绝大多数"预测项目"完全缺失的一环。
4. **金融级严谨性迁移**：Walk-Forward + purge/embargo + 嵌套 CV + Diebold-Mariano + White's SPA/DSR 多重检验校正，把量化回测的防坑经验完整搬进彩票场景。
5. **唯一的真实价值模块有数学保证**：组合覆盖优化（covering design + ILP + 多样性/去重）不依赖预测，收益是确定性的组合设计改进。
6. **风险教育内建为产品功能**：EV 恒定 -1 元/注、破产概率模拟、"保证中 6 红需 221 万元"——用可交互数字替代说教。
7. **工程闭环完整**：抓取→清洗→特征→建模→回测→API→前端→监控→CI，全链路可复现（seed + git_sha + data_snapshot_hash 三重锁定）。
8. **合规设计前置**：服务端硬编码免责与 EV 字段、禁用词库、不做代购/倍投/追号、AGPL 防止被包装成付费荐号——把社会责任写进架构而非文档。

> **一句话交付物**：一个能用数据、统计检验和可复现实验，公开证明"彩票不可预测"、并在此基础上提供真实（组合优化）价值的完整工程系统。
