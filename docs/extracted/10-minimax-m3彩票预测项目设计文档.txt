彩票预测项目科学实现方案 · 项目设计文档


版本: v1.0
角色: 高级数据工程师 / 机器学习工程师
立场: 数据工程 + 概率统计 + 策略回测平台,不做号码预测
关键结论前置: 彩票每期独立,任何"单期号码预测"模型长期期望值均为负,本项目目标是搭建一个严谨的数据流水线、统计可视化与策略回测平台,作为数据工程实战与概率论科普载体。

1. 项目背景
• 中国彩票年销量 2023 年约 5800 亿元(福彩 + 体彩),双色球 / 大乐透长期占据主流彩种。
• 市面所谓"预测"多为玄学、骗局或幸存者偏差叙事,缺乏可复现的数据工程。
• 真正可落地的价值在三个维度:
1. 数据工程实战: 采集、清洗、特征、回测、可视化、API 全链路。
2. 概率论科普: 用真实数据演示大数定律、独立性、回归均值、负 EV。
3. 策略回测框架: 任意过滤规则、组合策略可在真实历史数据上验证 ROI,验证"长期不可盈利"这一数学事实。

2. 项目真实目标
❌ 不做的事 | ✅ 真正要做的事
预测下期中奖号码 | 统计历史号码的分布特征、组合结构、冷热趋势
声称能提高中奖率 | 用回测量化每种策略的真实 ROI、最大回撤、夏普
玄学 / 星座 / 风水 | 严谨的特征工程 + 模型对比 + 数学证明
引导付费 / 加群 | 开源、可复现、可审查

核心交付: 一个 LotteryLab 平台,提供历史数据、统计可视化、策略回测 API,文档中所有声明均附数学依据。

3. 彩票预测是否可行的统计学解释
3.1 三条铁律
1. 每期独立: 双色球红球 33 选 6 + 蓝球 16 选 1,组合数 C(33,6)×16 ≈ 1772 万。每期摇奖为独立随机过程,前一期结果对后一期无任何信息量。
2. 大数定律: 当样本 N → ∞,任意号码出现频率趋近 1/33(红球)或 1/16(蓝球)。
3. 负期望值: 投注额固定(2 元),返奖率约 65–73%(双色球 ~66%、大乐透 ~65%),数学上长期必亏。
3.2 蒙特卡洛验证
设定每期固定投注 2 元,跑 10000 期共 20000 元,模拟 1000 次,资金曲线分布:
• 期望终值 ≈ -6800 元(对应返奖率 66%)。
• 最大回撤几乎 100% 出现。
• 这就是"长期负 EV"的实证。
3.3 那项目能研究什么?
• 号码分布特征: 频次、间隔、组合结构(和值、跨度、AC 值、奇偶比、区间比)的历史分布。
• 策略回测: 任意过滤规则在历史数据上的真实表现,验证"过滤后仍负 EV"。
• 资金管理: 凯利公式、Kelly fraction 在负 EV 游戏中为何失效。
• 销售额 / 奖池预测: 这些宏观数据有真实时序模式,可用 Prophet / XGBoost。

6. 数据清洗规则
1. 唯一性: (code, lottery_type) 联合唯一,UPSERT。
2. 范围校验: 红球 ∈ [1,33],蓝球 ∈ [1,16],否则置 NULL 并标记脏数据。
3. 去重校验: 红球互不相同。
4. 缺失处理:
◦ draw_date 缺失 → 用前一期 + 2/3 天推算后人工核查。
◦ pool_amount 缺失 → 用前后两期线性插值。
◦ prize_1_amount 缺失且 prize_1_count=0 → 填 0。
5. 异常检测:
◦ 单期销售额偏离滚动均值 3σ → 标记,但保留。
◦ 一等奖金额上限 1000 万,超出截断。
6. 类型转换: 字符串金额 → NUMERIC,带千分位逗号处理。
7. 增量: 每次拉取写入临时表,比对差异后再合并,避免脏写。

8. 模型方案对比
重要声明: 表中"号码预测"类模型 均不优于随机,仅作为研究方法对比,验证"模型无能为力"这一数学事实。"辅助预测"类模型对销售额/奖池等宏观时序有效。
模型 | 目标 | 评估 | 结论
频次统计 | 热冷号分布 | 与理论均匀分布的 χ² 检验 | 长期 p > 0.05,无显著偏离
XGBoost 回归 | 销售额 / 奖池 | RMSE / MAPE | 节假日特征显著,MAPE ~8%
Prophet | 销售额趋势 | MAPE | 适合长期趋势 + 节假日
LSTM | 时序建模 | RMSE | 与 Prophet 相当,无明显优势
Bayesian Beta | 号码后验概率 | KL 散度 | 长期趋近 1/33
Monte Carlo | 资金曲线模拟 | 终值分布、回撤 | 100% 验证负 EV
过滤规则策略 | 组合筛选 | ROI、回撤 | 所有过滤规则 ROI < -30%

所有模型输出均不直接给"下期号码",仅用于研究与可视化。

9. 回测框架设计
9.1 事件驱动架构
DrawEvent(期号, 开奖号码, 销售额, ...)  → Strategy(根据规则生成投注组合)  → Settlement(根据命中数计算奖金)  → Portfolio(更新资金曲线)  → Metrics(计算指标)
9.2 策略类型
类型 | 描述
固定单式 | 每期 1 注,2 元
复式 | 红球选 7–12 + 蓝球选 1–3,全组合
胆拖 | 1–5 胆码 + 拖码
旋转矩阵 | 覆盖指定红球的所有 6 选 N 组合
过滤 + 复式 | 叠加过滤规则

9.3 可用过滤规则(可叠加)
• 和值 ∈ [a, b]
• 跨度 ∈ [a, b]
• 奇偶比 ∈ {2:4, 3:3, 4:2}
• 大小比 ∈ {2:4, 3:3, 4:2}
• 三区比 ∈ 白名单
• 重号数 ∈ [0, 2]
• AC 值 ∈ [a, b]
• 冷热号数 ∈ [a, b]
9.4 核心指标
指标 | 公式
总投入 | Σ 每期投注额
总奖金 | Σ 中奖金额
净收益 | 总奖金 - 总投入
ROI | 净收益 / 总投入
最大回撤 | 资金曲线峰值 - 谷值
夏普比率 | (mean - rf) / std
命中率 | 中奖期数 / 总期数
凯利分数 | (bp - q) / b(b=赔率,p=胜率,q=1-p),在负 EV 下为负,不应投注

9.5 并发与性能
• 用 multiprocessing 并行回测多策略。
• 大组合(如红球复式 12+蓝球 3 ≈ 1716 注)需在 1 期 < 50ms 完成结算。
• 整体回测 3000 期 < 60s。

10. 评估指标体系
10.1 不用 / 为什么不用
• Accuracy / Precision / Recall: 适用二分类且样本均衡,本场景命中率 < 0.0001%(一等奖),统计噪声远大于信号。
• F1 / AUC: 同上,且基线随机模型 AUC ≈ 0.5,模型微扰可能给假阳性。
10.2 用什么
类别 | 指标
分布层 | χ² 拟合优度、KS 检验、Jensen-Shannon 散度
策略层 | ROI、最大回撤、夏普、终值分布(MC)
概率层 | 期望值 EV、凯利分数、置信区间
宏观层 | 销售额 MAPE、奖池 MAPE

10.3 基准
• 随机投注(每期 1 注): 长期 ROI ≈ -34%。
• 任何过滤策略: 必须显著跑赢该基准才算"有效",但数学上不可能。

14. 风险与合规说明
14.1 必须展示的声明
1. 本平台 不提供 任何"下期号码预测",所有内容仅用于数据研究、概率论科普与教育。
2. 彩票是 独立随机事件,任何"提高中奖率"的宣传均为虚假宣传。
3. 长期投注数学上 必然亏损(负 EV),请勿将彩票作为投资工具。
4. 未满 18 周岁请勿访问本平台涉及"投注"相关内容的页面。
5. 数据来源: 中国福利彩票官方 / 中国体育彩票官方,数据如有差异以官方为准。
14.2 法律边界
• 中国大陆: 不接入任何互联网售彩接口,仅做数据展示。
• 不收集用户身份信息、不诱导充值、不提供"内部消息"。
• 用户生成内容(UGC,如有)需审核过滤敏感词。
• 海外合规: 若服务范围扩展,需评估当地博彩法规。
14.3 技术层风险
• 第三方数据源变更导致采集失败 → 监控 + 多源降级。
• 回测任务过载 → 队列限流 + 单 IP 并发 ≤ 2。
• 接口被滥用 → 限流 + WAF。
14.4 模型风险
• 任何"看似有效"的策略均为 过拟合历史数据 或 幸存者偏差。
• 必须用 样本外回测(滚动窗口) + 蒙特卡洛验证。
• 在文档和 UI 中显式标注每个策略的样本内/外 ROI。
