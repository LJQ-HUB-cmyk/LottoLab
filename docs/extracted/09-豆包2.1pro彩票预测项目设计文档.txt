1. 项目背景
全球彩票市场年规模超 3000 亿美元，中国福利彩票与体育彩票年销售额合计超 5000 亿元人民币。大量彩民依赖"感觉""走势图""专家推荐"选号，缺乏系统化、数据驱动的决策工具。
核心矛盾：彩票本质是独立随机事件，但彩民有强烈的数据分析与辅助决策需求。市场上现有产品要么是纯玄学（解梦、星座），要么是简陋的历史统计表格，缺少工程化、统计学严谨、可解释的预测辅助系统。
本项目定位为基于历史数据的概率分析与选号辅助平台，不承诺中奖，而是提供数据驱动的号码组合建议、风险评估与回测工具。

2. 项目真实目标
层级 | 目标 | 可量化指标
P0 | 历史数据全量采集与清洗 | 覆盖双色球/大乐透/Fast3 等主流彩种，数据完整率 ≥99.5%

3. 彩票预测可行性的统计学解释
3.1 基本事实
• 独立同分布（i.i.d.）假设：正规彩票每期摇奖在物理上独立，理论上历史开奖不影响未来结果。
• 均匀分布：在公平摇奖前提下，每个号码被抽中概率相等（如双色球红球 1/33，蓝球 1/16）。
• 大数定律：样本量足够大时，各号码出现频率趋近理论概率。
3.2 为什么"看起来"有规律
现象 | 统计学解释
热号/冷号 | 小样本下的随机波动（赌徒谬误的反面），短期频率偏离理论值是正常的
连号/重号 | 在组合空间中，连号组合的实际占比并不低（如双色球 6 红球中出现连号的概率约 47%）
遗漏值回归 | 回归均值是统计趋势，不构成对单次事件的预测依据
和值/跨度分布 | 组合层面确实存在近似正态分布，可缩小组合空间但无法确定具体号码

3.3 工程上可行的事
1. 组合过滤：基于历史和值/跨度/奇偶比/大小比分布，过滤掉概率极低的组合（如全奇、全偶、全大连号），将 33 选 6 的 1,107,568 种组合缩减至统计高频区间内的约 30-50 万种。
2. 概率加权选号：在承认独立性的前提下，用贝叶斯更新或频率统计为号码赋予权重，生成加权随机组合——比纯随机更符合"历史分布特征"。
3. 风险分散：避免与大量彩民选择的热门号码（生日号 1-31、规律排列）撞号，降低"中奖后平分奖金"的期望损失。
4. 回测验证：任何策略必须在历史数据上验证，区分"统计噪声"与"微弱信号"。
3.4 诚实声明
本系统是概率辅助工具，不是预测机器。所有推荐基于统计分布和组合优化，不保证任何中奖结果。长期期望值为负（彩票返奖率约 50%），请理性购彩。

6. 数据清洗规则
6.1 数据采集校验
规则 | 处理方式
期号格式校验 | 正则匹配 ^\d{7}$（年+期号），不匹配则标记异常
号码范围校验 | 红球 ∈ [1, redmax]，蓝球 ∈ [1, bluemax]，越界则丢弃并告警
号码唯一性 | 同一色球内不得重复，重复则丢弃并告警
号码排序 | 存储前统一升序排序，便于查询和比较
开奖日期校验 | 与彩种 draw_days 匹配，非开奖日数据告警

• 单期缺失：标记并在下一次抓取时补全
• 连续多期缺失：触发告警 + 切换备用数据源

8. 模型方案对比
8.1 候选模型
模型 | 原理 | 优点 | 缺点 | 适用场景
频率加权采样 | 按历史出现频率加权随机抽样 | 简单、可解释、速度快 | 忽略独立性假设，实际效果≈随机 | 基准线/Baseline
马尔可夫链 | 基于状态转移概率预测下期号码出现概率 | 建模状态依赖，可解释 | 状态空间大，转移矩阵稀疏 | 号码遗漏状态转移
贝叶斯更新 | 先验=均匀分布，用历史数据更新后验概率 | 理论严谨，可融入领域知识 | 对独立事件后验≈先验 | 概率校准、组合权重
XGBoost 分类 | 对每个号码预测"出现/不出现"二分类 | 能捕捉非线性特征交互 | 样本不平衡严重，易过拟合 | 特征重要性分析、辅助筛选
LSTM 序列 | 用序列模型学习开奖号码时序模式 | 能建模长程依赖 | 数据量相对不足，容易过拟合噪声 | 实验对比/论文探索
组合优化（核心） | 基于约束规划/遗传算法，从高频组合空间采样 | 实用性强，可过滤低概组合 | 非"预测"，是组合选择 | 主模型，线上推荐

8.2 推荐方案：组合优化 + 概率加权混合
最终推荐 = 组合优化（约束过滤） × 概率加权（贝叶斯/频率） × 反热门调整
组合优化约束条件（可配置）：
// pythonCONSTRAINTS = {    "sum_range": (70, 130),           # 和值 70% 置信区间    "span_range": (18, 30),           # 跨度范围    "odd_even_ratio": [(3,3),(2,4),(4,2)],  # 允许奇偶比    "big_small_ratio": [(3,3),(2,4),(4,2)], # 允许大小比    "consecutive_max": 2,             # 最大连号长度    "same_tail_max": 2,               # 同尾号最多2个    "zone_min": [1,1,1],              # 三区间各至少1个}
生成算法：
1. 从全组合空间中按约束条件过滤 → 候选集 C（约 30-50 万注）
2. 计算每注的概率得分：score = Σ log(P(ball_i)) + combo_bonus
3. 加入反热门惩罚：score -= popularity_penalty
4. 按 score 加权采样，返回 N 注推荐
5. 确保推荐组合之间 Jaccard 相似度 < 阈值（增加多样性）

9. 回测框架
9.1 回测引擎设计
// pythonclass BacktestEngine:    """    滚动窗口回测：    - 训练窗口：最近 N 期（如 100 期）    - 测试窗口：下 1 期    - 步长：1 期    - 模拟玩法：每期买 M 注，每注 2 元    """    def __init__(self, lottery_code: str, strategy: Strategy,                 train_window: int = 100,                 tickets_per_draw: int = 5):        self.lottery = lottery_code        self.strategy = strategy        self.train_window = train_window        self.tickets_per_draw = tickets_per_draw    def run(self, start_issue: str, end_issue: str) -> BacktestResult:        results = []        for issue in issues_between(start_issue, end_issue):            # 1. 取训练数据            train_data = self.get_history_before(issue, self.train_window)            # 2. 训练/更新策略参数            self.strategy.fit(train_data)            # 3. 生成推荐号码            tickets = self.strategy.predict(self.tickets_per_draw)            # 4. 对比实际开奖结果            actual = self.get_draw_result(issue)            prize = self.calculate_prize(tickets, actual, self.lottery)            results.append({                "issue": issue,                "tickets": tickets,                "actual": actual,                "cost": self.tickets_per_draw * 2,                "prize": prize,                "hit_level": self.get_hit_level(tickets, actual)            })        return self.aggregate(results)

9.3 基准对比
每个策略回测时必须同时跑以下基准：
1. 纯随机选号：random.sample 生成
2. 机选模拟：模拟彩票店机选（纯均匀随机）
3. 热门号策略：选最近频率最高的号码
4. 冷门号策略：选遗漏最大的号码
策略必须显著优于基准（p < 0.05）才可标记为"有效"。

10. 评估指标
10.1 回测指标
指标 | 公式 | 说明
总投入 | Σ(期数 × 注数 × 2) | -
总中奖金额 | Σ 每期中奖额 | -
净收益 | 总中奖金额 - 总投入 | 长期应为负
ROI | 净收益 / 总投入 | 期望约 -50%（返奖率）
命中率 | 中奖期数 / 总期数 | 至少中六等奖的期数占比
最大回撤 | max(peaktotrough_loss) | 连续亏损的最大金额
夏普比率 | (meanreturn - rf) / stdreturn | 风险调整收益（这里基本无意义，仅形式计算）
各奖级命中次数 | count(prize_level) | 重点看三至六等奖命中率

10.2 模型离线指标（针对 XGBoost 二分类）
指标 | 用途
AUC-ROC | 区分能力（但因样本不平衡需配合 PR-AUC）
PR-AUC | 不平衡场景下的精度-召回曲线下面积
Precision@K | Top-K 推荐号码的命中率
Recall@K | 实际开奖号码出现在 Top-K 中的比例
Brier Score | 概率校准质量

指标 | 采集方式
